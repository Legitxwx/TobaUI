Toba Ultra UI Library

Welcome to the ultimate hub for the Toba UI Library. Toba is a universally compatible, ultra-modern, and highly responsive UI framework designed for Roblox Lua environments. Powered by Lucide icons and smart automatic layouts.

Bootstrapping the Library

Execute Toba via `loadstring` from your hosting source to initialize the framework securely.

lua 
local Toba = loadstring(game:HttpGet("https://raw.githubusercontent.com/Legitxwx/TobaUI/refs/heads/main/UI.lua"))()

Creating a Window

Initialize the main interface. Toba automatically handles UI scaling, responsive centering, and floating toggles.

lua 
local Window = Toba.CreateWindow({
    Title = "Toba Ultra",
    Subtitle = "Mega UI Library",
    Author = "YourName",
    Version = "2.0",
    Icon = "home",
    Theme = "dark",
    Size = UDim2.new(0, 920, 0, 680),
    Locked = false,
    ExecutorDisplay = true
})

Tabs & Sections

Organize your elements cleanly with smooth animated tab switching and collapsible sections.

lua 
local MainTab = Window:AddTab({
    Title = "Main",
    Icon = "home"
})

local Controls = MainTab:AddSection({
    Title = "Controls"
})

Button

Standard interactive button with hover states and click callbacks.

lua 
Controls:Button({
    Text = "Click Me",
    Callback = function()
        print("Button clicked")
    end
})

Toggle

Smooth animated switches for boolean states.

lua 
Controls:Toggle({
    Text = "Enabled",
    Default = true,
    Callback = function(state)
        print("Toggle:", state)
    end
})

Slider

Draggable numerical inputs bounded by minimum and maximum parameters.

lua 
Controls:Slider({
    Text = "Speed",
    Min = 0,
    Max = 100,
    Default = 30,
    Callback = function(value)
        print("Slider:", value)
    end
})

Textbox Input

Keyboard-friendly text entry with placeholder support.

lua 
Controls:Textbox({
    Placeholder = "Type here...",
    Callback = function(text)
        print("Textbox:", text)
    end
})

Dropdowns

Single and multi-select dropdown menus with built-in search functionality.

lua 
-- Single Select
Controls:Dropdown({
    Text = "Pick",
    Options = {"One", "Two", "Three"},
    Callback = function(option)
        print("Dropdown:", option)
    end
})

-- Multi Select
Controls:MultiDropdown({
    Text = "Multi Select",
    Options = {"A", "B", "C"},
    Callback = function(list)
        print("Multi:", table.concat(list, ", "))
    end
})

Keybinds

Interactive hardware input capturing for rapid execution triggers.

lua 
Controls:Keybind({
    Text = "Bind Key",
    Default = Enum.KeyCode.F,
    Callback = function(key)
        print("Keybind:", key)
    end
})

Color Picker

Visual RGB/HSV selection tool. Example below dynamically updates the Toba theme accent.

lua 
Controls:ColorPicker({
    Text = "Accent",
    Default = Color3.fromRGB(255, 85, 95),
    Callback = function(color)
        Window:SetAccent(color)
    end
})

Configuration System

Native support for reading, writing, exporting, and importing configurations directly via the executor file system or JSON payloads.

lua 
-- Local File System
Window:SaveConfig("myconf")
Window:LoadConfig("myconf")

-- JSON Export/Import
local json = Window:ExportConfig("myconf")
Window:ImportConfig(json, "imported")

Notifications

Built-in popup alerts with highly polished entry and exit animations.

lua 
Window:Notify("Hello", "Toba loaded successfully", 4)
